🥳 Automatic Birthday Wisher

This project automatically wishes birthdays to my friends using GitHub Actions.
It reads names and birthdates from a CSV file, checks daily, and sends birthday wishes automatically through Gmail.

Right now, it’s working fully with Gmail (I’ve tested it).
I also planned to integrate WhatsApp API for sending wishes there too — it’s a bit tricky, so I’ll add it later once it’s stable.

✨ Features

Reads data from a simple CSV file

Runs automatically every day using GitHub Actions

Sends birthday wishes via Gmail

Future update: WhatsApp message integration

No need to host or manually run anything

🛠️ Tech Used

Python for automation

GitHub Actions for scheduling

Gmail API for sending emails

💡 Why I Built This

I wanted to make something that runs on its own and helps me never miss a friend’s birthday.
Also, it was a great way to practice automation and learn how to use GitHub Actions and APIs in a real project.
